## Where it stands

Smart Object Foundations is the tutorial set for a project in the MDes Prototyping course at CCA: connect an ESP32 to the browser with WebSerial, then process a pulse sensor's signal in p5.js in three stages, from raw waveform to heartbeats per minute, with two side quests (Bluetooth streaming, browser to ESP32). It has tests for every stage and a code example gallery published on GitHub Pages, which answers. The last change, on 13 Mar 2026, added links to the Stage 3 extension demos; nothing has changed since.
